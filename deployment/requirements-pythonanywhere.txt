# Trimmed for the Telegram bot on PythonAnywhere's free tier (512MB disk quota).
#
# Omits easyocr, rembg, onnxruntime, opencv-python-headless, scipy from the root
# requirements.txt: easyocr is never imported anywhere in the codebase, and the
# other four are only reachable through the `use_onnx_bg=True` background-removal
# path, which only the web form's advanced option sets - the Telegram bot never
# does. Each is wrapped in try/except at its import site, so skipping them here
# degrades that one optional feature instead of crashing anything the bot uses.
#
# Also omits firebase-admin: its dependency tree (grpcio, protobuf,
# google-cloud-firestore, google-cloud-storage, google-api-python-client,
# cryptography...) is the single heaviest thing in the original requirements -
# easily the actual cause of a "disk quota exceeded" install failure. Not
# needed anyway for this host: PythonAnywhere runs one always-on process with
# a persistent disk, so session_store.py/blob_store.py's local-file fallback
# (what runs when firebase-admin isn't installed, per firebase_service.py's
# ImportError guard) is already correct here - the multi-instance problem
# Firestore solves on Cloud Run doesn't exist on this host.
