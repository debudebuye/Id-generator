# Free Crop Mode - User Guide

## ✅ What Was Fixed

The cropper now allows you to **move each side independently** without affecting other sides!

## 🎯 How It Works

### Default Mode: FREE ASPECT RATIO

By default, the cropper starts in **Free** mode, which means:
- ✅ Drag **left edge** → Only left side moves
- ✅ Drag **right edge** → Only right side moves
- ✅ Drag **top edge** → Only top side moves
- ✅ Drag **bottom edge** → Only bottom side moves
- ✅ Drag **corners** → Two adjacent sides move together
- ✅ Drag **inside box** → Entire crop box moves

### Aspect Ratio Buttons

You can switch between different modes:

1. **Free** (Default)
   - Move any side independently
   - No constraints
   - Perfect for custom crops

2. **1:1 (Square)**
   - Maintains square shape
   - Good for profile photos
   - All sides move proportionally

3. **16:10 (ID Card)**
   - Standard ID card ratio
   - Good for front/back ID images
   - Maintains rectangular shape

4. **4:3 (Standard)**
   - Common photo ratio
   - Good for general images
   - Maintains proportions

## 🎮 Step-by-Step Usage

### To Crop Freely (Move One Side at a Time):

1. Upload your image
2. Cropper opens in **Free** mode (default)
3. Click and drag any edge:
   - **Left edge** → Adjusts left boundary only
   - **Right edge** → Adjusts right boundary only
   - **Top edge** → Adjusts top boundary only
   - **Bottom edge** → Adjusts bottom boundary only
4. Click "Apply Crop"

### To Use Fixed Aspect Ratio:

1. Upload your image
2. Click one of the aspect ratio buttons:
   - **Free** - No constraints
   - **1:1** - Square
   - **16:10** - ID card
   - **4:3** - Standard photo
3. Now all sides move proportionally
4. Click "Apply Crop"

## 💡 Pro Tips

### For Maximum Control:
1. Start in **Free** mode
2. Drag each edge to exactly where you want it
3. Fine-tune by dragging corners
4. Use "Move Image" if you need to reposition the photo

### For Quick Crops:
1. Click **1:1** for square crops
2. Click **16:10** for ID cards
3. Position the crop box
4. Apply

### For Precise Alignment:
1. Use **Free** mode
2. Drag top edge to align with top of ID
3. Drag bottom edge to align with bottom
4. Drag left edge to align with left side
5. Drag right edge to align with right side

## 🔧 Controls Summary

### Edge Controls (Free Mode):
- **Drag Top Edge** → Move top boundary
- **Drag Bottom Edge** → Move bottom boundary
- **Drag Left Edge** → Move left boundary
- **Drag Right Edge** → Move right boundary
- **Drag Corner** → Move two adjacent sides
- **Drag Inside** → Move entire crop box

### Aspect Ratio Buttons:
- **Free** → Independent side movement
- **1:1** → Square (profile photos)
- **16:10** → ID card ratio
- **4:3** → Standard photo ratio

### Other Controls:
- **Move Image** → Switch to move the image
- **Rotate Left/Right** → Rotate 90°
- **Reset** → Start over
- **Apply Crop** → Save the crop

## 🐛 Troubleshooting

### All Sides Move Together?
- Click the **Free** button to unlock aspect ratio
- Now each side moves independently

### Can't Move Just One Side?
- Make sure you're in **Free** mode (not 1:1, 16:10, or 4:3)
- Drag the edge, not the corner
- Drag from the middle of the edge

### Crop Box Snaps Back?
- You might be in a fixed aspect ratio mode
- Click **Free** to remove constraints

### Want Square Crop?
- Click **1:1** button
- Now it maintains square shape

## 📱 Mobile Usage

On mobile devices:
- **Touch and drag edge** → Move that edge only (Free mode)
- **Touch and drag corner** → Move two sides
- **Tap aspect ratio buttons** → Switch modes
- **Pinch to zoom** → Zoom image
